# Family Memoriess

A simple and elegant landing page for a family photo gallery. The page introduces the collection of family memories and provides a button that directs visitors to the main gallery.

## 📌 About the Project

**Family Memories** is a basic HTML and CSS website designed to showcase memorable family moments.

The landing page contains a title, a short description, and a button that links to the `gallery.html` page.

## ✨ Features

* Simple landing page design
* Family memories introduction
* Gallery navigation button
* External CSS styling
* Clean and minimal layout
* Responsive design can be added through CSS

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📄 Main Page

### Landing Page

The landing page contains:

* **Title:** Our Memories
* **Description:** A collection of moments captured with love and joy.
* **Gallery Button:** Directs the user to `gallery.html`

## 🔗 Navigation

The gallery button uses:

```html
<a href="gallery.html" class="btn">
    Go to Gallery →
</a>
```

When the button is clicked, the visitor is redirected to the `gallery.html` page.

## 🚀 How to Run

1. Open the project folder.
2. Make sure `index.html`, `landing.css`, and `gallery.html` are in the correct locations.
3. Open `index.html` in a web browser.
4. Click **Go to Gallery →** to open the gallery page.

You can also use **Live Server** in Visual Studio Code.

## 🎨 CSS

The page uses an external stylesheet:

```html
<link rel="stylesheet" href="landing.css">
```

The `landing.css` file is responsible for the appearance and layout of the landing page.
